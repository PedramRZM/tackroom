# Decisions

One short file per decision about architecture, the data model, infrastructure or an
integration: `NNNN-short-title.md`, numbered in order. Written before the work that depends on
it, and reviewed by the owner. A decision is not edited after it is accepted; a later decision
replaces it and says so.

    # NNNN. Title

    Date: YYYY-MM-DD   Status: proposed | accepted | replaced by NNNN

    ## Context
    What forced a choice, and the constraints that matter.

    ## Decision
    What we will do, stated plainly.

    ## Consequences
    What becomes easier, what becomes harder, what we are now committed to.

    ## Alternatives rejected
    Each with the reason, in a line or two.
