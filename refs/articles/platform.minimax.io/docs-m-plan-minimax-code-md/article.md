# MiniMax Code

> Use the latest MiniMax M-series models in MiniMax Code.

Sign in with the MiniMax account you used to subscribe to M Plan to access your subscription benefits. No separate subscription or M Plan API key setup is required.

## Get started

> [tab] Desktop
>
> **1. Download and sign in**
>
> Download and install the macOS or Windows app from the [MiniMax Code download page](https://agent.minimax.io/download), then sign in with the MiniMax account you used to subscribe to M Plan.
>
> **2. Start using MiniMax Code**
>
> Enter a task on the home page to get started. Drag in reference files or select a local project folder as needed.

> [tab] Mobile
>
> **1. Download and sign in**
>
> Visit the [MiniMax Code download page](https://agent.minimax.io/download) and use the **Mobile App** entry to download the iOS or Android app. Sign in with the MiniMax account you used to subscribe to M Plan.
>
> **2. Continue your tasks**
>
> Check task progress, add instructions, and remotely continue your desktop tasks.

> [tab] Web
>
> **1. Open and sign in**
>
> Open [MiniMax Code on the web](https://agent.minimax.io) and sign in with the MiniMax account you used to subscribe to M Plan.
>
> **2. Start a cloud task**
>
> Describe your goal and upload reference files as needed. The web app is suited to online research, content creation, and organizing information. Use the desktop app when you need direct access to project files on your computer.

> [tab] CLI
>
> **1. Install the MiniMax Code CLI**
>
> Run the official installer for your operating system:
>
> ```bash macOS, Linux, WSL theme={null}
> curl -fsSL https://filecdn.minimax.chat/public/install.sh | bash
> ```
>
> ```powershell Windows (PowerShell) theme={null}
> irm https://filecdn.minimax.chat/public/install.ps1 | iex
> ```
>
> Reopen your terminal and run `mcode --version` to verify the installation. See the [official installation instructions](https://github.com/MiniMax-AI/minimax-code#quick-start) for other options.
>
> **2. Sign in to MiniMax**
>
> Run the following command and complete sign-in in your browser:
>
> ```bash theme={null}
> mcode login --region global
> ```
>
> **3. Start in your project**
>
> From your project directory, run:
>
> ```bash theme={null}
> mcode
> ```
>
> Enter `/status` to check your account, use `/provider` to choose a model, and describe your development task. See the [MiniMax Code CLI docs](https://github.com/MiniMax-AI/minimax-code/tree/main/docs) for more options.

## M Plan benefits and usage

MiniMax Code and other AI tools connected with your M Plan API key share the same M Plan usage limits. Available models, features, and usage depend on your subscription tier. Check **Settings > Usage & Models** in MiniMax Code or visit [Plan Details](https://platform.minimax.io/console/plan).

See [M Plan tiers and available models](https://platform.minimax.io/docs/m-plan/intro.md), [usage details](https://platform.minimax.io/docs/m-plan/usage-rules.md), and the [FAQ](https://platform.minimax.io/docs/m-plan/faq.md#minimax-code).
