Agent view is an *incredible* experience new experience for TUI.

It's super easy to start a new session in any directory you want. The new session uses the directory that the cursor is on.

Renaming is extremely critical for maintaining a clean view. Use /rename or set up a UserPromptSubmit hook to rename.
