Veeeery excited about mods, it’s basically middleware for Claude Code!

You can create a TypeScript function that intercepts CC's internal events (tool calls, prompts, model requests and renders) and change what actually happens. You can also add your own UI and commands!

> Quoting @ClaudeDevs: You can now mod Claude Code:
> 
> - Change how it behaves
> - Customize the UI
> - Swap in your own features
> 
> Write one with a few lines of TypeScript, or have Claude build it for you. Mods ship inside plugins, so you install them with /plugin in the CLI or desktop app.
