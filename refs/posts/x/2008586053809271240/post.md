5/ additionalDirectories

Claude is sandboxed to your project by default.

Need to reference a shared library, monorepo sibling, or docs folder? Use the additionalDirectories setting to grant access.

"permissions": {
  "additionalDirectories": ["../shared-lib", "~/docs"]
}
