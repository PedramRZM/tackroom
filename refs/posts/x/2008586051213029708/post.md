3/ cleanupPeriodDays

Auto-delete old sessions after X days. Default is 30.

Set to 0 for a fresh start every time.

"cleanupPeriodDays": 0

Good for keeping things clean. On the flip side, set it to a big number to keep your session history retained for longer.
