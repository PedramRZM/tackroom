Out now: Teams, aka. Agent Swarms in Claude Code

Team are experimental, and use a lot of tokens. See the docs for how to enable, and let us know what you think! https://code.claude.com/docs/en/agent-teams

> Quoting @lydiahallie: Claude Code now supports agent teams (in research preview)
> 
> Instead of a single agent working through a task sequentially, a lead agent can delegate to multiple teammates that work in parallel to research, debug, and build while coordinating with each other.
> 
> Try it out today by enabling agent teams in your settings.json!
